# Quick start

## Install

```sh
bun add a1sheet        # npm / pnpm / yarn all fine
```

React is a **peer** dependency, and an optional one — the root entry point does
not need it.

## Render something

```tsx
import { createWorkbook } from "a1sheet";
import { Spreadsheet } from "a1sheet/react";

const wb = createWorkbook(["Budget"]);
Object.assign(wb.sheets[0].cells, {
  "0_0": "Item", "0_1": "Qty", "0_2": "Price", "0_3": "Total",
  "1_0": "Widget", "1_1": "3", "1_2": "4.50", "1_3": "=B2*C2",
});

<Spreadsheet defaultWorkbook={wb} height={480} />
```

There is no stylesheet to import. Styles are injected as one `<style>` tag with
a class prefix, so dropping this into an existing app needs no build-config
change.

## Cell addressing, once

Everything internal is `"${row}_${col}"`, **zero-indexed**. Everything the user
sees is A1 notation, **one-indexed**. So `"1_3"` is the cell labelled `D2`, and
a formula in it referring to its own row says `B2`.

```ts
import { cellKey, toA1, parseCellRef } from "a1sheet";

cellKey(1, 3);          // "1_3"
toA1(1, 3);             // "D2"
parseCellRef("D2");     // { row: 1, col: 3 }
```

Two parallel maps, never merged:

```ts
sheet.cells["1_3"]   // "=B2*C2"        — raw text, "=" prefix means formula
sheet.styles["1_3"]  // { bold: true }  — appearance only
```

## Reading a real file

```ts
import { readWorkbookFile } from "a1sheet";

const { format, sheets } = await readWorkbookFile(file);   // .xlsx or .csv
```

It is async because it is paced: a large file yields to the browser between
chunks instead of freezing the tab. See
[Data and files](?path=/docs/data-and-files-import--docs) for progress and
cancellation.
